# Contributing to Emo A I Pro

Thank you for your interest in contributing to Emo A I Pro.  
We welcome contributions of all kinds — code, documentation, design, testing, and ideas.

This document explains how to contribute effectively and respectfully.

---

## 🧩 Ways to Contribute

- Fix bugs or submit improvements  
- Add new features  
- Improve documentation  
- Report issues or suggest enhancements  
- Help review pull requests  
- Share feedback and ideas  

---

## 🛠 Development Setup

1. Fork the repository  
2. Clone your fork  
3. Install dependencies  
4. Create a new branch for your changes  
5. Commit with clear messages  
6. Push and open a pull request  

---

## 🔍 Pull Request Guidelines

- Keep PRs focused on a single change  
- Write clear commit messages  
- Include screenshots or logs when relevant  
- Ensure your code builds without errors  
- Follow the project’s coding style  
- Be respectful and constructive in discussions  

---

## 🐞 Reporting Issues

When reporting a bug, include:

- Steps to reproduce  
- Expected behavior  
- Actual behavior  
- Logs or screenshots  
- Environment details  

---

## 🤝 Code of Conduct

By participating in this project, you agree to follow the  
**Emo A I Pro Code of Conduct**.
